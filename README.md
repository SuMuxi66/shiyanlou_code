
# 🎮 Python 小工具集合

这是一个有趣的Python程序集合，包含各种小游戏和实用工具！

## 📦 包含内容

### 游戏类
1. **猜数字游戏** - 猜1-100的随机数字
2. **石头剪刀布** - 经典的猜拳游戏
3. **跳7游戏** - 打印1-100跳过与7相关的数字
4. **贪吃蛇游戏** - 命令行版的贪吃蛇

### 实用工具
5. **简易计算器** - 支持基本四则运算
6. **简易记事本** - 记录和查看笔记
7. **两数之和算法** - LeetCode经典题目

## 🚀 使用方法

运行主菜单：
```bash
python3 game_hub.py
```

或者直接运行单个程序：
```bash
python3 猜数字.py
python3 石头剪刀布.py
python3 计算器.py
```
